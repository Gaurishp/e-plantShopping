# Paradise Nursery - Online Plant Shopping Application

## Project Description
Paradise Nursery is a React-based online plant shopping application that allows users to explore and purchase houseplants through a simple and user-friendly interface. The application provides a landing page, categorized plant listings, a shopping cart, and quantity management.

## Project Objectives
- Build a responsive online plant shopping application using React.
- Display houseplants with their images, names, prices, and categories.
- Allow users to add plants to the shopping cart.
- Implement cart quantity controls and item removal.
- Calculate the total number of items and the total purchase cost dynamically.
- Manage application cart state using Redux Toolkit.

## Features
- **Landing Page:** Displays the company name, description, background image, and Get Started button.
- **Product Listing:** Displays houseplants organized into categories.
- **Add to Cart:** Adds selected plants to the shopping cart and updates the cart count.
- **Shopping Cart:** Displays selected plants, quantities, individual prices, and total cost.
- **Quantity Management:** Allows users to increase or decrease plant quantities and remove items.
- **Checkout:** Displays a Coming Soon message.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Gaurishp/e-plantShopping.git
   ```

2. Navigate to the project directory:

   ```bash
   cd e-plantShopping
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Project Structure

- `src/App.jsx` - Main application and page components.
- `src/CartSlice.jsx` - Redux cart state and actions.
- `src/store.js` - Redux store configuration.
- `src/App.css` - Application styling.
- `public/` - Public static assets.
- `package.json` - Project dependencies and scripts.
